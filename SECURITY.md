# Security Policy

## Supported Versions

Currently supported release line:

- `0.1.x`

## Reporting a Vulnerability

Please report vulnerabilities privately to the maintainers.

- Contact: `security@trafficmind.com`
- Include: impact, reproduction steps, affected versions, and possible mitigation

## Response SLA

- Initial acknowledgement: within 3 business days
- Triage status update: within 7 business days
- Fix or mitigation plan: as soon as severity is confirmed

Do not open public issues for unpatched vulnerabilities.
